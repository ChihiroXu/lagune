# DESIGN

DESIGN defines the visual language used to present LAGUNE research. It separates brand identity from reusable design tokens and from guidance for maps and other visualizations.

- [`brand/identity.md`](brand/identity.md) — platform name, positioning, voice, and identity usage.
- [`tokens/README.md`](tokens/README.md) — organization and governance of semantic visual tokens.
- [`cartography/standards.md`](cartography/standards.md) — map-specific communication and cartographic practice.
- [`visualization/standards.md`](visualization/standards.md) — standards for charts and other non-map visualizations.

Standards should support legibility, accessibility, honest representation of uncertainty, and clear attribution. Do not imply that a final palette, logo, or cartographic default has been approved before it is documented.
