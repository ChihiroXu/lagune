# DESIGN

DESIGN defines the visual language used to present LAGUNE research. The [LAGUNE visual system](brand/LAGUNE_VISUAL_SYSTEM.md) is the canonical source for brand identity, approved assets, visual tokens, and reusable component primitives.

- [`brand/identity.md`](brand/identity.md) — concise name, positioning, and voice reference; defer asset and style details to the canonical visual system.
- [`styles/tokens.css`](styles/tokens.css) — canonical semantic tokens, documented in [`tokens/README.md`](tokens/README.md).
- [`styles/components.css`](styles/components.css) — canonical framework-neutral component primitives and responsive helpers.
- [`cartography/standards.md`](cartography/standards.md) — map-specific communication and cartographic practice.
- [`visualization/standards.md`](visualization/standards.md) — standards for charts and other non-map visualizations.

Standards should support legibility, accessibility, honest representation of uncertainty, and clear attribution. Brand colors are not substitutes for data-specific map or chart palettes.
